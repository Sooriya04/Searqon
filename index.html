Architecture

Core Subsystems

Designed to execute local search, anti-bot resolution, and structured extraction in a predictable, high-throughput pipeline.

SUBSYSTEM 01
Multi-Engine Search Aggregation
Dispatches search queries simultaneously across SearXNG, DuckDuckGo, Wikipedia, and Arxiv. Merges disparate hit lists with reciprocal rank fusion (RRF) and deduplicates pages by cryptographic SHA-256 content hashes.
SUBSYSTEM 02
4-Tier Anti-Bot Escalation Ladder
Starts requests on fast, low-overhead HTTP. If a target presents bot barriers or JavaScript challenges, Searqon automatically escalates through browser header spoofing, headless CDP (Lightpanda/Camoufox), and residential proxies.
SUBSYSTEM 03
Token-Bounded Extraction & Chunking
Strips ads, tracking scripts, and navigation boilerplate using readability algorithms. Produces clean Markdown with word counts, heading breadcrumbs, and pre-chunked sliding token windows ready for vector database ingestion.
SUBSYSTEM 04
Agent Protocols: MCP & UTCP
Direct native support for Model Context Protocol (stdio and SSE transports) and the Universal Tool Calling Protocol (UTCP). AI agents inspect the schema manifest at runtime without custom adapter glue.
Stealth Resolution

Anti-Bot Escalation Ladder

Each target URL starts at Tier 1 and transparently progresses only when challenges or blocks are encountered.

Tier Resolution Mechanism Typical Latency Trigger Threshold
Tier 1 Direct HTTP client (Go standard library net/http) 50–200ms Standard initial fetch attempt.
Tier 2 Browser header spoofing, TLS fingerprint imitation 200–500ms HTTP 403 Forbidden or static header inspection.
Tier 3 Headless CDP browser (Lightpanda / Camoufox) 1.5–3.5s Cloudflare 5s challenge, heavy client-side JavaScript.
Tier 4 Residential proxy pool rotation 2.5–6.0s IP rate-limiting, ASN block, or geographic restriction.
