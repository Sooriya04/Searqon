Engine Architecture

How Searqon ingests, purifies, and structures web intelligence without external SaaS dependencies.

Phase 1 · Discovery
Federated Search
Queries SearXNG, DuckDuckGo Lite, Wikipedia, and ArXiv concurrently. Deduplicates canonical URLs and ranks candidates via BM25 with freshness decay scoring.
SearXNG BM25 Ranker Deduplication
Phase 2 · Extraction
Token-Dense Markdown
Strips tracking scripts, ads, and navigation boilerplate. Produces clean Markdown with word counts and structured metadata ready for LLM context windows and RAG embeddings.
Clean Markdown RAG Chunks Ollama LLM
Phase 3 · Storage
Dual Storage Engine
Runs out of the box on embedded pure-Go SQLite with WAL mode, FTS5 full-text indexing, and vector tables. Seamlessly switches to PostgreSQL and Redis L1 cache when configured.
SQLite FTS5 PostgreSQL Redis L1

4-Tier Anti-Bot Escalation

Searqon avoids heavy browser compute on ordinary pages. It starts lightweight and escalates automatically through stealth tiers only when challenges are detected.

Tier Mechanism Target Protections Avg Latency
Tier 1 Fast HTTP/2 Client
Pure Go connection pooling, Brotli/Gzip decoding		 Unprotected pages & API endpoints 2–10 ms
Tier 2 Fingerprint & TLS Spoofing
Chrome 128 / Safari 17 client hints (`Sec-CH-UA`)		 Basic WAFs & rate-limit challenges 20–50 ms
Tier 3 Headless Browser Subprocess
Lightpanda / Camoufox JS DOM evaluation		 Cloudflare Turnstile, React/Next SPAs 1.5–3.5 s
Tier 4 Residential Proxy Fallback
Rotating residential & datacenter proxy pool		 Hard IP bans & geo-restrictions 2.0–4.0 s

Crawler Identity

                    

                        Searqon identifies itself on every crawl request with an explicit identity string pointing to this documentation. It respects crawl-delays, skips non-public content, and enforces a default 5 req/sec domain rate limit.
