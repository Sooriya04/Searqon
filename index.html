Architecture

Search → Fetch → Chunk → Rank

One HTTP call triggers the full pipeline. Searqon handles provider routing, anti-bot escalation, content extraction, and BM25 ranking internally.

Multi-Engine Search
Routes queries across SearXNG, DuckDuckGo, Wikipedia, and Arxiv. Merges results with reciprocal rank fusion and deduplicates by content hash.
4-Tier Anti-Bot
Escalates automatically: fast HTTP → spoofed browser headers → Lightpanda/Camoufox headless CDP → residential proxy. Zero manual configuration.
Clean Markdown Output
Strips ads, navigation boilerplate, and tracking scripts. Returns structured Markdown with word count and content hash — ready for LLM context windows.
SSE Streaming
GET /search/stream emits progressive Server-Sent Events: discovery → scrape → synthesis. No polling. Works directly in any HTTP client or AI agent SDK.
MCP + UTCP Protocols
Native Model Context Protocol server and Universal Tool Calling Protocol support. Drop Searqon into any MCP-compatible agent without writing glue code.
RAG-Ready Chunking
POST /scrape/chunked splits content into token windows (500 tokens, 50-token overlap) with heading breadcrumbs and BM25 scores. Ready for vector DB ingestion.
Anti-Bot Escalation

Four tiers. Automatic fallback.

Each request starts at Tier 1 and escalates only when blocked. No configuration required — Searqon detects bot challenges and retries at the next tier.

Tier Method Latency Use Case
T1 Direct HTTP with Go stdlib 50–200 ms Static sites, open APIs, most news domains
T2 Spoofed browser headers + TLS fingerprint 200–600 ms Cloudflare-lite, basic bot detection
T3 Lightpanda / Camoufox headless browser via CDP 1–4 s JavaScript-rendered pages, Cloudflare 5s challenge
T4 Residential proxy pool rotation 2–8 s Aggressive geo-blocking, IP-rate-limited targets
